# 다음 책장

다 읽은 책을 등록하고 교환 신청을 기록하는 동네 책 교환 데모입니다. 제목과 저자로 검색할 수 있고, 등록과 신청 상태는 현재 브라우저에 저장됩니다.

## 실행

이 폴더에서 아래 명령을 실행하고 브라우저에서 http://127.0.0.1:8000 을 엽니다.

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

## 모의 점검 결과

상단의 **모의 점검 결과**에서 입력 검증, 접근 제어, 오류 메시지의 예시 상태를 볼 수 있습니다. 같은 항목의 샘플 JSON은 `sample-findings.json`에서 확인할 수 있습니다. 이 데이터는 결과 화면 확인용이며 스캐너와 연동되어 있지 않습니다.
