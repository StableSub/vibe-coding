# 수조 404

심야 수족관을 배경으로 한 한국어 웹 추리 게임입니다. 404번 수조가 비었다는 신고가 들어왔지만 같은 시각 CCTV에는 금붕어가 보입니다. 회차별 영상을 대조하고, 야간 사육사에게 질문하고, 모은 증거로 최종 판단을 내려 보세요.

## 로컬 실행

Node.js 22.13 이상에서 저장소 루트 기준으로 실행합니다. 별도로 설치할 패키지는 없습니다.

```sh
cd tank-404
npm start
```

브라우저에서 [로컬 게임](http://127.0.0.1:4040/)을 엽니다. 진행 기록은 로컬 SQLite 데이터베이스에 저장됩니다.

## 검증과 빌드

```sh
npm test
npm run build
```

빌드 결과는 `dist/server/index.js`에 생성됩니다.
